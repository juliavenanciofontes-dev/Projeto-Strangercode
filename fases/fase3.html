O Cálculo do Dano

O Demogorgon está se aproximando. Mike precisa calcular quanto dano a equipe consegue causar. Para isso, você precisa criar uma função.

SUA MISSÃO

  • Crie uma função chamada calcularDano.
  • Receba dois parâmetros: força e multiplicador.
  • Calcule o dano.
  • Use return para devolver o resultado.
  • Chame a função e mostre o resultado.
Uma função pode receber parâmetros: function calcularDano( forca, multiplicador ) { return forca * multiplicador; }
function calcularDano( forca, multiplicador ) { let dano = forca * multiplicador; return dano; } let resultado = calcularDano( 10, 2 ); document.write( "Dano causado: " + resultado );
