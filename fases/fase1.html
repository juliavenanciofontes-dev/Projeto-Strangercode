A Ficha de Onze

Hawkins, 1983. Onze acabou de escapar do Laboratório Nacional. Para entrar na turma do Mike, ela precisa de uma ficha de identidade.

SUA MISSÃO

  • Pergunte o nome usando prompt().
  • Pergunte a idade usando parseInt().
  • Pergunte os waffles usando parseFloat().
  • Mostre tudo usando document.write().
Você pode começar assim: let nome = prompt("Qual o nome?"); Para a idade: let idade = parseInt( prompt("Qual a idade?") );
let nome = prompt("Qual o nome?"); let idade = parseInt( prompt("Qual a idade?") ); let waffles = parseFloat( prompt("Quantos waffles?") ); document.write( "Nome: " + nome ); document.write( "<br>Idade: " + idade ); document.write( "<br>Waffles: " + waffles );
