Batalha por Turnos

O Demogorgon apareceu! Agora a batalha acontece em turnos. Você precisa atacar até que a vida do inimigo chegue a zero.

SUA MISSÃO

  • Crie uma variável para a vida do inimigo.
  • Use while para controlar a batalha.
  • Diminua a vida a cada ataque.
  • Use for para repetir ataques.
while (vida > 0) { vida = vida - dano; } Use for para repetir ataques.
let vida = 100; let dano = 20; while (vida > 0) { vida -= dano; document.write( "Vida: " + vida + "<br>" ); } for ( let i = 0; i < 3; i++ ) { document.write( "Ataque realizado!<br>" ); }
