O Portal do Mundo Invertido

O portal para o Mundo Invertido foi aberto novamente, e Hawkins está em perigo! Para fechá-lo, você precisará coletar energia suficiente e usar seus conhecimentos de JavaScript para concluir a missão. Organize as energias coletadas, calcule o total e descubra se já é possível fechar o portal.

SUA MISSÃO

  • Etapa 1 — Prepare as variáveis
    1. Crie uma variável chamada energias e inicialize-a como um vetor vazio.
    2. Crie uma variável chamada total e atribua a ela o valor 0. Ela será responsável por armazenar a quantidade total de energia coletada.
  • Etapa 2 — Prepare a interface
    1. No HTML, crie um botão com o texto "Coletar energia" e um identificador que permita acessá-lo pelo JavaScript.
    2. Crie outro botão com o texto "Fechar portal".
    3. Crie três elementos HTML para exibir:
      • A quantidade total de energia acumulada.
      • O resultado da última ação realizada.
      • A lista de energias coletadas.
  • Etapa 3 — Conecte os elementos ao JavaScript
    1. Utilize document.getElementById() para armazenar em variáveis os três elementos criados para exibir as informações.
    2. Configure o botão de coleta para executar uma função chamada coletarEnergia() quando for clicado.
    3. Configure o botão de fechar o portal para executar uma função chamada fecharPortal() quando for clicado.
  • Etapa 4 — Implemente a coleta de energia
    1. Crie a função coletarEnergia().
    2. Dentro dela, gere um número aleatório inteiro entre 1 e 10. Esse será o valor de energia obtido pelo jogador.
    3. Adicione o valor gerado ao vetor energias, utilizando o método push().
    4. Atualize a variável total com a soma de todas as energias coletadas. Para isso:
      • Primeiro, zere o valor de total.
      • Depois, utilize um laço de repetição for para percorrer o vetor.
      • A cada repetição, adicione o valor do elemento atual à variável total.
    5. Atualize a página para exibir o total de energia acumulada e a lista de valores coletados.
    6. Exiba uma mensagem informando quantos pontos de energia foram obtidos naquela coleta.
  • Etapa 5 — Feche o portal
    1. Crie a função fecharPortal().
    2. Dentro dela, utilize uma estrutura condicional if para verificar se o total de energia acumulada é maior ou igual a 30.
    3. Se a condição for verdadeira:
      • Exiba uma mensagem informando que o portal foi fechado e que Hawkins foi salva.
      • Desative os dois botões para impedir novas ações.
    4. Caso contrário, utilize else para exibir uma mensagem informando que a energia ainda é insuficiente e que o jogador precisa coletar mais.
Comece criando o vetor e as variáveis que serão usadas no jogo.

No JavaScript, lembre-se:

• document.getElementById() encontra elementos da página.

• onclick chama uma função quando o botão é clicado.

• Math.floor(Math.random() * 10) + 1 gera um número de 1 a 10.

• push() adiciona um valor ao final do vetor.

• Um for pode percorrer o vetor e somar seus valores.

• Use if e else para verificar se o total chegou a 30.

Você pode atualizar a tela sempre que o jogador coletar energia ou tentar fechar o portal.

function coletarEnergia() {
    let energia = Math.floor(Math.random() * 10) + 1;

    energias.push(energia);

    total = 0;

    for (let i = 0; i < energias.length; i++) {
        total += energias[i];
    }

    energiaNaTela.innerText = total;

    historico.innerText =
        "Energias coletadas: " + energias.join(", ");

    resultado.innerText =
        "Você coletou " + energia + " pontos de energia!";
}
