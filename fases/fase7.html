Você chegou ao Mundo Invertido. Vecna está esperando. Para derrotá-lo, você precisará usar tudo o que aprendeu.

SUA MISSÃO

  • Use variáveis.
  • Use prompt().
  • Use if e else.
  • Crie uma função com return.
  • Use while e for.
  • Use um vetor.
  • Use getElementById() e addEventListener().
Use tudo o que aprendeu: • prompt() • parseInt() • if / else • function • return • while • for • vetor • HTML + JavaScript
let jogador = prompt("Seu nome"); let forca = parseInt( prompt("Sua força") ); let vidaVecna = 100; let itens = [ "espada", "lanterna" ]; function calcularDano( forca ) { if (forca > 5) { return forca * 2; } else { return forca; } } let dano = calcularDano(forca); while ( vidaVecna > 0 ) { vidaVecna -= dano; document.write( "Vida do Vecna: " + vidaVecna + "<br>" ); } for ( let i = 0; i < itens.length; i++ ) { console.log( itens[i] ); } let botao = document.getElementById( "luzes" ); botao.addEventListener( "click", function() { alert( "Vecna foi derrotado!" ); } );
