Vecna e o Mundo Invertido

Você chegou ao coração do Mundo Invertido. Vecna está diante de você e o portal está prestes a ser aberto. Para derrotá-lo, você precisará construir seu próprio sistema de batalha usando tudo o que aprendeu.

SUA MISSÃO

  • Crie variáveis para representar o jogador e a vida de Vecna.
  • No HTML, crie um input para informar a força do ataque.
  • Crie um button para realizar o ataque e um p para mostrar o resultado.
  • Use document.getElementById() para acessar os elementos da página.
  • Use .value para pegar o valor digitado no input e converta-o para número.
  • Crie uma função que receba a força do ataque, calcule o dano e utilize return.
  • A cada ataque, diminua a vida de Vecna e registre o dano em um vetor.
  • Use if e else para verificar se Vecna foi derrotado.
  • Utilize innerText ou innerHTML para atualizar o resultado na página.
  • Use um for ou while para percorrer o vetor e mostrar o histórico dos ataques.
Comece pelo HTML! Pense nos três elementos que o jogador precisa: um campo para digitar, um botão para atacar e um elemento para mostrar o resultado. No JavaScript, lembre-se: • document.getElementById() encontra elementos da página. • .value pega o que foi digitado no input. • Number() pode converter o valor para número. • Uma function pode receber a força do ataque e devolver o dano usando return. • O vetor pode guardar os ataques realizados. • if e else podem verificar se Vecna ainda está vivo. • innerText ou innerHTML podem atualizar o que aparece na página. • for ou while podem percorrer o vetor e mostrar o histórico dos ataques. Pense neste caminho: Jogador digita → JavaScript pega o valor → calcula o dano → diminui a vida de Vecna → registra o ataque → mostra o resultado na página. Não esqueça: nesta fase, você não precisa utilizar prompt() para receber o ataque. 

let vidaVecna = 100;

let ataques = [];


const inputAtaque =
    document.getElementById("forcaAtaque");


const botaoAtacar =
    document.getElementById("btnAtacar");


const resultado =
    document.getElementById("resultado");


const vidaNaTela =
    document.getElementById("vidaVecna");


const historico =
    document.getElementById("historico");


function calcularDano(forca) {

    return forca * 2;

}


botaoAtacar.addEventListener(
    "click",
    function() {

        if (vidaVecna <= 0) {

            resultado.innerText =
                "Vecna já foi derrotado!";

            return;

        }


        let forca =
            Number(inputAtaque.value);


        if (
            forca <= 0 ||
            inputAtaque.value === ""
        ) {

            resultado.innerText =
                "Digite uma força de ataque válida!";

            return;

        }


        let dano =
            calcularDano(forca);


        vidaVecna -= dano;


        if (vidaVecna < 0) {

            vidaVecna = 0;

        }


        ataques.push(dano);


        vidaNaTela.innerText =
            vidaVecna;


        if (vidaVecna === 0) {

            resultado.innerText =
                "Você derrotou Vecna e fechou o portal!";

            botaoAtacar.disabled = true;

        }

        else {

            resultado.innerText =
                "Você causou " +
                dano +
                " de dano! Vecna ainda possui " +
                vidaVecna +
                " de vida.";

        }


        let textoHistorico = "";


        for (
            let i = 0;
            i < ataques.length;
            i++
        ) {

            textoHistorico +=
                "Ataque " +
                (i + 1) +
                ": " +
                ataques[i] +
                " de dano<br>";

        }


        historico.innerHTML =
            textoHistorico;


        inputAtaque.value = "";

    }
);
