A Porta do Laboratório

Hawkins, 1983. Onze encontrou uma porta misteriosa no Laboratório Nacional. Para descobrir se ela pode entrar, você precisa criar um sistema de decisão usando condições.

SUA MISSÃO

  • Pergunte o nível de acesso do jogador.
  • Use parseInt() para transformar a resposta em número.
  • Use if para verificar o nível de acesso.
  • Use else caso o jogador não tenha acesso.
  • Mostre uma mensagem usando document.write().
Você pode perguntar o nível assim: let nivel = parseInt( prompt("Digite seu nível") ); Depois: if (nivel >= 5) { document.write( "Acesso permitido!" ); } else { document.write( "Acesso negado!" ); }
let nivel = parseInt( prompt( "Digite seu nível de acesso" ) ); if (nivel >= 5) { document.write( "Acesso permitido!" ); } else { document.write( "Acesso negado!" ); }
